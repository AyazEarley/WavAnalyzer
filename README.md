# Command Line Wav Analyzer in C

I'm taking digitial signal processing right now, and in order to solidify my knowledge, I decided to impliment the algorithms I've learned. I started with the conceptually grounded but inefficient versions, before working my way up to better optimizations.

What I achieved:

- Safely read and parsed a .wav file, byte by byte
- Implement basic DSP algorithms like peak amplitude, RMS and zero-crossing
- Implement a naiveDFT
- Implement an FFT
- Implement an in place FFT
- Hand code everything myself, no libraries, no LLMs
